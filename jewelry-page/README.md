# 玖光 JOAILLERIE · 高级珠宝品牌官网首页模板（jewelry-page）

虚构品牌「玖光」的高级珠宝整站首页模板 —— 极简顶栏 + 全屏氛围 hero + 三大系列陈列（项链/戒指/耳饰）+ 工艺故事 + 高级定制四步 + 预约鉴赏表单 + 法务三件套页脚，商用级，可直接改字上线。

`huafire3d fx-lab — original implementation`

## 参考来源（只学布局结构与交互编排，源码/文案/图片全部原创）

参考类型：Cartier / Tiffany & Co. 官网。学到的布局点：

1. **极简顶栏**：左品牌印徽（中文「玖光」+ 英文 JOAILLERIE 双行）、中导航（系列/工艺/高级定制/预约鉴赏）、右幽灵预约钮；滚动 40px 后毛玻璃（`backdrop-filter: blur` + 墨黑半透明 + 金色细线）。
2. **全屏高级氛围 hero**：黑色底 + 中央金色线稿项链 SVG（缓慢呼吸）+ vignette 暗角，大标题两行遮罩升起（"光有九种 / 爱只一种"，字距 .28em），双 CTA（实心金钮 + 幽灵钮），底部滚动提示线。
3. **系列陈列三卡**：项链/戒指/耳饰各一张程序化线稿图（象牙底 + 深金线条），英文系列名（LUMIÈRE/ÉTERNITÉ/ONDE）+ 中文名 + 材质规格 + 明码标价（¥42,000 起）。
4. **工艺故事黑底区块**：左文案（327 道工序 / 终身免费保养）+ 右三行金色数字（工序/工时/年限量），数字滚动进场。
5. **高级定制四步**：01 面谈 → 02 画稿 → 03 选石 → 04 交付，横向四格，金色序号。
6. **预约鉴赏 CTA + 页脚**：深色预约卡（左文案右表单，手机号校验 + 成功态）→ 页脚（品牌/导航/联系/法务三件套弹窗/社交图标/版权行 + 备案行）。

## 动效拆解

1. **加载态**：墨黑全屏 loader（「玖光」金字 + 金色细线滑块），`window.load` 后最短 900ms 淡出，再触发 hero 标题升起；4 秒兜底放行（完成态必达）。
2. **主视觉动效（整页一个核心动效体系）**：珠宝卡片 hover **金色光泽扫过**（`::after` 斜切金色渐变带，`translateX(-260%)→480%`，1.15s `cubic-bezier(.22,1,.36,1)` 慢扫）+ 全页滚动 **stagger 入场**（`.reveal` + `data-i` 延迟 .12s 递增，1s 出场）。
3. **hero**：标题两行遮罩升起（`overflow:hidden` + 内层 `translateY(112%)→0`，第二行延迟 .18s）；项链线稿 9s 缓慢呼吸（透明度 + 缩放）；滚动提示线循环下落。
4. **导航**：滚动 40px 切换 `.scrolled` 毛玻璃；链接 hover 金色下划线生长；移动端汉堡 → 右侧全屏抽屉（遮罩 + X 关）。
5. **滚动 reveal**：`IntersectionObserver`（阈值 .12）给 `.reveal` 加 `.in`；无 JS 时不隐藏（`.js` 前缀），`prefers-reduced-motion` 下直达终态。
6. **数字滚动**：工艺区 327/42/300 进入视口后 `easeOutQuart` 1.4s 数到终值；无 IO 时直接写终值。
7. **手工细节**：全页 SVG `feTurbulence` 纸纹噪点（`overlay` 混合）；hero/工艺/预约卡 vignette 暗角；卡片 hover 上浮 8px + 内层线稿放大 1.05；社交图标 hover 金色圆钮上浮；按钮 hover 上浮 + 金色阴影。

## 配置参数（`src/main.js` 顶部）

- `CFG.navOffset = 40` —— 导航毛玻璃触发距离（px）。
- `CFG.revealThreshold = 0.12` —— 滚动 reveal 触发阈值。
- `CFG.loaderMin = 900` —— 加载态最短展示（ms）。
- `CFG.countDur = 1400` —— 数字滚动时长（ms）。
- `SITE` —— 站点信息变量（**买家改这里，一改全改**）：`name / phone / phoneHref / wechat / address / city / icp / year`。页脚与正文电话/微信/地址/备案行/年份均由 `data-site` / `data-site-href` 属性自动渲染。
- `LEGAL` —— 法务三件套文案对象（`privacy / terms / cookies`，每篇 `title + points` 数组），改文案只改这里。

## 法务三件套（弹窗实现）

- 页脚"网站政策"区三个按钮：**隐私政策 / 服务条款 / Cookie 政策**，点击弹模态弹窗（单弹窗壳 + JS 按 key 灌文案）。
- 关闭三通道：右上 X（hover 旋转 90°）、点击遮罩、ESC；打开时 `body overflow:hidden` 锁定背景滚动；焦点自动进关闭钮，关闭后回到原焦点。
- 移动端（≤640px）弹窗为全屏式（无圆角、撑满视口）。
- 三篇文案均为真实感中文通用条款（隐私 5 条 / 服务 5 条 / Cookie 5 条，覆盖预约确认、定制流程、定金、终身保养、标价口径），无 Lorem。
- 预约表单下方"提交即表示同意我们的隐私政策"链接同样触发弹窗。

## "看起来不像 AI 写的"六项自查

1. **克制**：整页只讲一个主视觉动效（卡片金色光泽扫过 + 滚动 stagger），不堆砌视差/3D/粒子。
2. **配色定死 3 色**：墨黑 #101010 + 香槟金 #C9A96A + 象牙 #F7F3EA 全页统一，无彩虹渐变；深金 #8a6d3f 只用于象牙底上的线稿描边（香槟金的深色变体，非第四色）。
3. **字体讲究**：衬线（宋体栈）大标题字距 .22–.55em、行高 1.5 有呼吸感；正文字距 .08–.3em；英文小字（JOAILLERIE/LUMIÈRE）字距 .42–.55em 做装饰。
4. **无 Lorem、无 emoji**：文案全部真实感中文短句（"光有九种，爱只一种""爪镶的四个爪，看起来像天生就长在钻石上"）；社交图标为 inline SVG 线稿；珠宝图为原创金色线稿 SVG。
5. **手工细节**：vignette 暗角、纸纹噪点、加载态、按钮微浮、卡片光泽扫过、数字滚动、表单成功态。
6. **easing 物理感**：`cubic-bezier(.22,1,.36,1)`（out-expo 系）做入场与光泽扫过，`easeOutQuart` 做数字滚动；hover 上浮慢（.6s），贵气不弹跳。

## 移动端说明

- ≤860px：汉堡菜单 → 右侧抽屉（含遮罩/X/ESC 关闭，点链接自动收起）；系列卡单列；工艺区上下排；预约卡上下排；导航 CTA 隐藏。
- ≤640px：定制四步单列；页脚单列；法务弹窗全屏式；hero 双 CTA 全宽。
- 触屏上卡片光泽扫过动效不触发（无 hover），stagger 入场与数字滚动正常工作。
