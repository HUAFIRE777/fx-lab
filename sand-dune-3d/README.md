# sand-dune-3d · 沙丘风场

数千沙粒沿实时风场流淌、贴着程序化沙丘做跳跃式搬运，相机以 Earth Studio 式缓慢 dolly 在沙丘上空漫游——风速滑杆、风向拨盘、三档沙丘形态（新月/横脊/星形）实时可调。`huafire3d fx-lab — original implementation`

## 参考与借鉴点

- **对标对象**：沙漠延时摄影的质感（低角度暖阳、沙脊高光、风蚀波纹）+ Earth Studio 式地形漫游手法（缓慢 dolly + 呼吸感高度起伏，不做大地形数据，只学运镜节奏）。
- **学的手法**（只学思路，不抄代码）：
  1. 沙丘=高度场网格顶点位移，而非贴图法线造假；脊线走向与风向存在物理关联（横向脊垂直于主风向）；
  2. 风沙搬运用"参数化流线"表达：粒子位置是 `f(生命)` 的纯函数，不做欧拉积分——风向突变时整场沙流同步改向，零拖尾残影；
  3. 沙粒跳跃（saltation）是风沙搬运的真实形态，粒子高度=丘面高度+跳跃包络，而非悬空乱飘。
- **代码原创声明**：三档沙丘高度函数（新月/横脊/星形三角混合）、流线粒子 shader（spawn 线+横向 meander+wobble）、风蚀波纹方向场、运镜+拖拽回正逻辑均为本模板独立编写；simplex 噪声采用 Ashima 公开标准实现（业界通用手法）；未接触任何原站源码。

## 动效拆解

| 模块 | 手法 |
|---|---|
| 沙丘高度场 | 顶点 shader：`duneH(p, mode)` = 大尺度 fbm 起伏 + 三档形态函数；`uMode` 0→2 连续值三角基混合，切换时指数缓动过渡（约 1.4s 肉眼完成），过渡中带一阵指数衰减的阵风 |
| 三档形态 | `m0 新月`（月牙形主脊+不对称系数）/`m1 横脊`（平行脊线组，包络收边）/`m2 星形`（中央峰+五条辐射臂）；法线为高度场数值偏导（顶点级，210×150 细分） |
| 沙粒流淌 | 5600 点（移动 2400）：每粒子 `life=fract(t·速率+seed)`；起点=逆风侧垂直于风向的播撒线，`pos=start+wind·(life·行程)`；横向 meander 用 snoise 扰动、振幅随风速放大；高度=`duneH(当前位置)`+跳跃包络 `|sin(life·跳频·π)|^1.3·跳幅`；头尾 alpha 淡入淡出消除循环跳变 |
| 风场 | 风向拨盘→目标向量，shader 内 `uWindVec` 按最短弧指数跟随；沙流、风蚀波纹、远尘三者共用同一风向，改向时整场同步转 |
| 风蚀波纹 | fragment：`sin(dot(gp, windDir)·6.5 + fbm·5)`，波峰线垂直于风向，随风向实时旋转；只做受光调制（`+sand·ripM·0.1·wrap`），不碰几何 |
| 光照 | 低角度暖阳包裹光 `wrap=(N·L+0.55)/1.55`；高度色带：洼地深棕→沙金→脊线米白；脊线沙粒闪光（`pow(...,90)` 窄高光） |
| 相机漫游 | 半径/高度/偏航角三正弦叠加缓慢漂移（周期 20–140s）；拖拽时 yaw/pitch 偏移接管，松手后 0.55/s 指数回正；双击复位 |
| 远尘 | 260 颗大尺寸极淡粒子（alpha≈0.03–0.05），只给空气纵深，不抢主视觉 |

## 配置参数

| 参数 | 位置 | 说明 |
|---|---|---|
| `PLANE_W / PLANE_H` | `src/main.js` | 沙丘平面尺寸（世界单位），默认 36 × 26 |
| `SEG` | `src/main.js` | 网格细分，桌面 210×150 / 移动 120×88 |
| `GRAIN_N` | `src/main.js` | 沙粒数，桌面 5600 / 移动 2400 |
| 风速滑杆 | 页面底部 | 0–100，默认 45；同时控制粒子速率/密度/跳幅/波纹对比度 |
| 风向拨盘 | 页面底部 | 拖拽旋转，0–360°，读数含十六方位（北/北东北/…）；支持键盘 ←→ 微调 |
| 形态按钮 | 页面底部 | 新月（0）/横脊（1）/星形（2），`uMode` 连续插值+阵风 |
| `SUN` | `src/main.js` | 太阳方向，默认低角度 `(-0.62, 0.34, -0.42)` |
| 配色 | `index.src.html :root` | 沙金 `#E8C47A` / 深棕 `#2A1E12` / 米白 `#F5EDDA`（严格三色） |
| 相机 | `src/main.js` | fov 42 / 半径 15.5±2 / 高 4.6±1.05 / 注视点 (0,1.2,0) |

## "看起来不像 AI 写的"六项自查

1. **克制**：整页只有一个主视觉动效（沙丘风场），其余只有滑块、拨盘、按钮 hover、标题淡入等微交互；远尘淡到几乎看不见，只为纵深存在。
2. **配色**：全页严格三色（沙金/深棕/米白），无彩虹渐变；沙丘明暗全部由光照+高度色带算出；地平线暖光是同色沙金的低透明径向渐变，非新增颜色。
3. **字体**：标题宋体栈、字号 clamp(52px, 8.6vw, 116px)、字距 .14em，大标题有呼吸感；层级 kicker → h1 → slogan → hint 四档分明；控制区用等宽字体读数。
4. **文案**：真实感中文短句（"风从不回头，沙丘替它记得方向。"），无 Lorem ipsum、无 emoji 符号列表。
5. **手工细节**：vignette + SVG 噪点颗粒（1.15s steps 跳动）、沙丘加载态（卷动横条）、拨盘 12 刻度、形态切换带阵风、滑块 thumb 悬停放大、按钮 hover 上浮、拖拽 grab/grabbing 光标、WebGL 失败兜底文案。
6. **easing**：全站无 linear——指数缓动跟随（`1-exp(-dt·k)`）驱动风速/风向/形态/相机回正；标题/控制坞入场用 `cubic-bezier(0.16,1,0.3,1)`；阵风指数衰减；加载条 var(--ease) 循环。

## 源码结构

```
sand-dune-3d/
├── index.src.html   # 开发版：结构 + 全部 CSS + importmap（three → vendor）
├── src/main.js      # 全部逻辑（ESM）：场景/沙丘 shader/沙粒/远尘/风场状态/运镜/三控件/加载
├── vendor/
│   └── three.module.js  # 本地 three@0.183.0（从 jellyfish-3d 复制，约 1.2MB）
├── index.html       # 打包成品（单文件，fx-singlefile.py 生成，勿手改）
└── README.md
```

`src/main.js` 内部分节：基础（renderer/scene/camera）→ sRGB 直值 → 共享 GLSL（snoise+fbm+三档 duneH）→ 沙丘网格 → 沙粒 Points → 远尘 Points → 状态/缓动 → 相机漫游+拖拽 → 风速滑杆/风向拨盘/形态三档 → 主循环 → 自适应/兜底。

## 重建方式

```bash
cd ~/workspace/fx-lab/sand-dune-3d
cp index.src.html index.html            # 打包器读 index.html 并原地改写（单向！改源码只动 index.src.html + src/）
python3 ~/workspace/bin/fx-singlefile.py sand-dune-3d
# 预览：浏览器打开 index.html（file:// 可跑，importmap 已是 data: URL）
```

注意：`index.src.html` 里 ESM 入口必须写 `src/main.js`（不能写 `./src/main.js`），否则打包器正则匹配不到、main.js 不会被内联（已踩过一次）。

## 移动端说明

- 断点 640px：标题缩小、hint 隐藏、控制坞换行居中、拨盘 86→70px、滑杆 170→130px。
- 触屏：画布 `touch-action:none`，单指拖拽旋转视角（pointer 事件统一鼠标/触屏）；拨盘支持手指旋转；双击复位视角。
- 性能：沙粒 5600→2400、细分 210×150→120×88、远尘 260→120；DPR 上限 2。
- `prefers-reduced-motion`：时间流速降为 0.25，动效变缓而非全停。
