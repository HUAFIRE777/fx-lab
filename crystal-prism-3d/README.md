# crystal-prism-3d · 棱镜之光

一句话介绍：一束白光穿过三角棱镜——边缘辉光随视角变色，右侧散出一道窄光谱，地面光斑跟着棱镜走，拖动旋转、滑杆调光束角度。`huafire3d fx-lab — original implementation`

## 参考与借鉴点

- **对标对象**：光学演示站的"棱镜色散"（入射光束 + 出射光谱扇 + 地面光斑的构图）。
- **学了哪几个手法**（只学手法，不抄代码）：
  1. 菲涅尔边缘辉光：棱镜边缘亮、中间透，玻璃感靠边缘不靠贴图；
  2. 窄光谱扇：五条细光带角度微差，色散是"一道"不是"一片"；
  3. 地面光斑跟棱镜走：光斑左右轻移、明暗呼吸，光才有落点。
- **代码原创声明**：辉光 shader、光束渐变、光谱扇、光斑跟随逻辑全部为手写 GLSL 与原创 JS，未引用任何原站源码；Three.js（MIT）仅作渲染载体。

## 动效拆解

| # | 动效 | 实现 |
|---|---|---|
| 1 | 棱镜辉光 | 自定义 ShaderMaterial：菲涅尔 `pow(1-dot(N,V),2)`，边缘在紫/冰蓝之间缓慢变色 |
| 2 | 入射光束 | Canvas 横向渐变贴图（左淡右亮、上下柔化），Additive 叠加 |
| 3 | 出射光谱扇 | 5 条细光带（红/橙/绿/青/紫），角度 -0.10～+0.10 扇形散开，透明度 0.5 |
| 4 | 地面光斑 | 径向渐变圆斑，x 位置跟 `sin(棱镜转角)` 轻移，透明度 0.65–0.85 呼吸 |
| 5 | 浮尘 | 300 点缓慢漂移，紫色微光 |
| 6 | 拖拽旋转带惯性 | pointer 拖拽 → 角速度，松手后 `exp(-dt·3.2)` 衰减；待机自转 |
| 7 | 光束角度滑杆 | -20°～+20°，光束组整体旋转，目标值经 `1-exp(-dt·4)` 平滑 |
| 8 | 色温预设 | 白光/暖光只调光束颜色，指数平滑过渡 |
| 9 | 加载态 | 「光正在穿过棱镜」+ 循环进度条；首帧+450ms / load+450ms / 3.2s / 5s 四重兜底必进完成态 |

## 配置参数

在 `src/main.js` 顶部 / uniform 处调整：

- `tgt.angle` 初值 `0`：光束角度（滑杆 -20～+20）
- 光谱扇角度 `-0.10 + i * 0.05`：五条光带的散开幅度
- 棱镜尺寸：三角柱半径 `1.15`、长 `2.6`
- 配色：`:root` 中 `--night:#0a0a12` `--white:#f8fafc` `--violet:#a78bfa`

## "看起来不像 AI 写的"六项自查

1. **克制**：全页只有一个主视觉动效（棱镜与光）；标题/控制条均为静态 UI，无第二主角。
2. **配色**：全页严格 3 色（墨夜 #0a0a12 / 月白 #f8fafc / 棱镜紫 #a78bfa），无彩虹渐变装饰；光谱扇是物理色散内容本身，且只有五条细线、低透明度。
3. **字体**：系统字体栈；巨型标题 `clamp(3rem,10vw,7.5rem)` 字距 -0.02em，kicker 字距 0.55em 大小 12px，层级分明。
4. **文案**：真实感中文短句（"一束白光，拆成一道光谱""光就换个方向走"），无 Lorem ipsum、无 emoji 符号列表。
5. **手工细节**：棱镜内芯细亮线、光束上下柔化、浮尘微光、滑杆 thumb 悬停发光、vignette + SVG 噪点、「光正在穿过棱镜」加载态。
6. **easing**：全部手写物理感缓动（`cubic-bezier(0.16,1,0.3,1)`、指数追踪 `1-exp(-dt·k)`），无默认 linear。
