# tide-3d · 潮汐涨落

月夜海湾的半日潮涨退循环：水位按 12.42 小时周期涨落，月相决定潮差大小——朔望大潮时潮差 4.8 米，上下弦小潮时只剩 2.0 米；天上的月亮带着真实明暗界线，水面铺开一条月光路。huafire3d fx-lab — original implementation。

## 参考与借鉴点

- **对标对象**：海边验潮站的延时摄影 + 潮汐表 App 的"大潮/小潮"概念。
- **学的三个手法**：① 潮汐表的信息层级——水位/涨退/潮差/月相四个读数一眼扫完；② 验潮标尺——真实港口都有一根黑白相间的杆子，水位变化肉眼可读；③ 月光路——月夜海面那条晃动的光带是"夜晚"的快捷方式。
- **代码原创声明**：以上只学手法。半日潮余弦模型、月相→潮差映射、月相着色器明暗界线、海浪/泡沫/湿沙 shader、礁石抖动几何、交互逻辑全部手写原创，未复制任何现成海洋/潮汐特效代码。

## 动效拆解

| 模块 | 手法 |
|---|---|
| 潮汐模型 | 半日潮 `level = amp·2.4·cos(2πh/12.42)`；月相→潮差 `amp = 0.71+0.29·cos(4π·phase)`（朔望=1.0，上下弦=0.42），切换月相时指数平滑过渡、无跳变 |
| 月亮 | 真球体 + 自定义月相着色器：明暗界线由月相解析算出（确定性，不依赖灯光），暗面留 0.055 地照微光；canvas 手绘月海暗斑纹理；additive 月晕 sprite |
| 海浪 | 顶点着色器三正弦叠加 + 解析法线；片元：深浅混合、掠射银调、月光镜面（pow 140）+ 噪声闪烁光路 |
| 岸线泡沫 | 水深 `depth = (tide+wave) − beachH(x,z)` 驱动：泡沫带 smoothstep + 向岸移动的条纹 +  lace 水线，全部程序化噪声 |
| 沙滩 | CPU 位移解析式海滩（含沙丘隆起）；湿沙带（水位上下 1 米渐变）+ 湿沙镜面微光 + 水线痕 |
| 礁石/标尺/浮标 | 抖动二十面体礁石（flat shading）；canvas 条纹验潮标尺；浮标随波起伏 + 灯光呼吸闪烁 |
| 天空 | 渐变穹顶 shader + 月晕染色；850 星点 shader 闪烁 |
| 演示按钮 | 「看一次涨潮/退潮」：解算下一个极值时刻，快进到极值前 1 模拟小时、×600 播放，播完自动恢复原速 |
| 相机 | 缓慢漂移 + 鼠标/触屏视差（lerp 跟随），lookAt 固定 |

## 配置参数表

| 参数 | 位置 | 默认 | 说明 |
|---|---|---|---|
| `MAXH` | main.js | 2.4 | 大潮半潮差（米）；潮差读数 = 2·amp·MAXH |
| `TIDE_PERIOD` | main.js | 12.42 | 半日潮周期（小时） |
| 月相 | 面板 8 按钮 | 望 | 朔/娥眉/上弦/盈凸/望/亏凸/下弦/残月；决定潮差与月盘明暗 |
| 时间加速 | 滑杆 | ×240 | 对数 1×–1000×；只加速潮汐与月行，不加速浪 |
| 演示 | 两按钮 | — | 跳到下一次高/低潮前 1 小时，×600 播放后自动恢复 |
| 暂停 | 按钮 | — | 冻结潮汐/时间推进，浪继续 |
| loader 兜底 | main.js | 3800ms | 超时强制进入完成态 |
| 配色 | CSS 变量 | — | `--bg:#06121f` 深海蓝 / `--ink:#DCE9F5` 月光银；水体另取深蓝 `#0A1F36` 系，严格 2–3 色 |

## 「看起来不像 AI 写的」六项自查

1. **克制**：整页只讲一个主视觉——潮汐涨落。礁石/标尺/浮标都是"读潮"的道具，不另起视觉主题。
2. **配色**：严格 2 色（#06121F 深海蓝 / #DCE9F5 月光银）+ 水体深蓝同系；禁用彩虹渐变；泡沫/月光都是银色单色。
3. **字体**：中文标题宋体衬线（系统字栈，零外部字体），英文 kicker 大字距（.42em），读数字体 tabular-nums，层级分明。
4. **文案**：真实感短句（"月亮把海水往上拽，岸就往后退一步"），无 Lorem ipsum、无 emoji 列表。
5. **手工细节**：vignette 暗角 + SVG feTurbulence 噪点覆盖层（pointer-events:none）；按钮 hover 上浮 + 光晕；滑杆 thumb hover 放大；月相按钮选中辉光；加载态进度条；浮标灯呼吸。
6. **easing**：全站 `cubic-bezier(.22,1,.36,1)`；潮汐用余弦（物理感）；月相/潮差切换用指数平滑，无跳变。

## 重建方式

```bash
cd ~/workspace/fx-lab/tide-3d
cp index.src.html index.html
python3 ~/workspace/bin/fx-singlefile.py tide-3d
```

改 `src/main.js` 或 `index.src.html` 后重新跑上面三行即可。**禁止对已打包的 index.html 重复跑 singlefile**（importmap 已是 data:URL、main.js 已是 bundle，单向）。

## 移动端说明

- 390×844 布局：标题区压缩（副文案隐藏），读数 4 项横排缩小，控制面板贴底全宽，note 与 footer 隐藏。
- 触屏：月相/按钮直接用 `click` 事件；`pointermove` 视差在触屏拖动时同样生效。
- 像素比上限 2；窄视口下月亮可能出画，月相信息由面板图标与读数承载。

## 踩坑记录

1. **月相灯光不确定性**：初版用 DirectionalLight 照月球算明暗界线，无头截图里满月显示为残月（灯光/层交互不符合预期）。修法：改写自定义 ShaderMaterial，界线由月相解析式直接算出，确定性 100%。
2. **月亮飞出画面**：初版仰角 0.62 rad，月盘在 FOV 上沿之外。修法：仰角降到 0.17±0.08 rad，恒在视野内。
3. **水面波浪坐标错位**：水面 mesh 有 z=-20 偏移，顶点着色器用局部坐标算波浪会与 JS 侧（浮标用）错位 20 米。修法：着色器内用 `modelMatrix` 还原世界坐标再算波。
4. **smoothstep 边反写**：`smoothstep(tide+1.1, tide+0.15, y)` 边 0>边 1 在 GLSL 里未定义。修法：写成 `1.0-smoothstep(tide+0.15, tide+1.1, y)`。
