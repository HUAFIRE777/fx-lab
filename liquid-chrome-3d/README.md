# liquid-chrome-3d · 液态铬

一句话介绍：一颗液态金属球——顶点噪声让表面缓慢流动，镜面反射手绘条纹环境光，拖动旋转带惯性，滚动加剧形变，镜面/磨砂两种表面。`huafire3d fx-lab — original implementation`

## 参考与借鉴点

- **对标对象**：产品渲染站的"液态金属 hero"（镜面球 + 条纹环境光 + 缓慢形变的构图）。
- **学了哪几个手法**（只学手法，不抄代码）：
  1. 条纹环境光：环境贴图里一道亮带，铬面反射才有"拉丝"的方向感；
  2. 顶点噪声形变：金属不是硬的，表面随时间缓慢起伏才像液体；
  3. 拖拽惯性：松手后继续转一会儿，靠指数衰减收住。
- **代码原创声明**：环境贴图、噪声位移、拖拽惯性、表面切换逻辑全部为手写 GLSL 与原创 JS，未引用任何原站源码；Three.js（MIT）仅作渲染载体。

## 动效拆解

| # | 动效 | 实现 |
|---|---|---|
| 1 | 液态形变 | 顶点着色器注入 simplex 噪声：沿法线位移 `0.14 × 流动强度`，双频叠加 |
| 2 | 镜面反射 | MeshStandardMaterial 金属度 1.0 + 手绘 equirect 环境贴图（亮带 + 一道暖色条纹） |
| 3 | 拖拽旋转带惯性 | pointer 拖拽 → 角速度，松手后 `exp(-dt·3.2)` 衰减；待机自转 0.12 rad/s |
| 4 | 滚动加剧形变 | wheel 增量累积 morphBoost（上限 1.6），指数衰减 |
| 5 | 流动强度滑杆 | 0–2×，目标值经 `1-exp(-dt·4)` 平滑 |
| 6 | 表面预设 | 镜面粗糙度 0.08 / 磨砂 0.38，只调粗糙度，指数平滑过渡 |
| 7 | 底部微光 | 一道琥珀色 additive 光晕，透明度 0.04–0.06 呼吸 |
| 8 | 加载态 | 「金属正在熔化」+ 循环进度条；首帧+450ms / load+450ms / 3.2s / 5s 四重兜底必进完成态 |

## 配置参数

在 `src/main.js` 顶部 / uniform 处调整：

- `tgt.flow` 初值 `1.0`：流动强度（滑杆 0–200 → 0–2×）
- 位移幅度 `0.14`：形变强度系数
- 噪声频率 `1.6` / `3.4`：大起伏 / 细纹
- 球体半径 `1.45`，细分 `5`（20480 面）
- 配色：`:root` 中 `--night:#0b0b0e` `--silver:#d4d4d8` `--amber:#f59e0b`

## "看起来不像 AI 写的"六项自查

1. **克制**：全页只有一个主视觉动效（金属球）；标题/控制条均为静态 UI，无第二主角。
2. **配色**：全页严格 3 色（炭黑 #0b0b0e / 铬银 #d4d4d8 / 琥珀 #f59e0b），无彩虹渐变；暖色只出现在一条环境条纹和 UI 点缀。
3. **字体**：系统字体栈；巨型标题 `clamp(3rem,10vw,7.5rem)` 字距 -0.02em，kicker 字距 0.55em 大小 12px，层级分明。
4. **文案**：真实感中文短句（"一块会呼吸的铬""它比你想象的更软"），无 Lorem ipsum、无 emoji 符号列表。
5. **手工细节**：环境贴图手绘亮带+暖色条纹、底部微光呼吸、滑杆 thumb 悬停发光、vignette + SVG 噪点、「金属正在熔化」加载态。
6. **easing**：全部手写物理感缓动（`cubic-bezier(0.16,1,0.3,1)`、指数追踪 `1-exp(-dt·k)`），无默认 linear。
