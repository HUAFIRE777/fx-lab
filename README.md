## 怎么用

1. 去[画廊](https://eazyopc.com/fx-lab)找到喜欢的效果，点 **下载 ZIP**
2. 解压，双击 `index.html` 即看
3. 改文案、换配色，直接上线用（MIT 协议，不用署名也行，但欢迎 Star ⭐）

## 本地开发（贡献模板）

```bash
git clone https://github.com/HUAFIRE777/fx-lab.git
cd fx-lab
# 画廊聚合页生成（增量：只处理新增/缺截图的模板）
NODE_PATH=/tmp/hcshot/node_modules node tools/build-gallery.mjs
```
