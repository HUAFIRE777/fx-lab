# bonsai-3d · 盆景

程序化盆景延时生长：递归生成的虬曲树干逐段抽枝、叶簇随枝展叶；春夏秋冬一键换景（叶色渐变 + 花瓣/落叶/飞雪粒子 + 冬日积雪），时间轴可拖回任意生长瞬间——为东方美学 / 文创 / 冥想类 hero 而生的一盆数字盆景。huafire3d fx-lab — original implementation。

## 参考与借鉴点

- **对标对象**：苏州留园冠云峰盆景 + 延时摄影里的植物生长片（BBC《植物的私生活》式抽枝节奏）。
- **学的三个手法**：① 盆景"虬曲"——主干 S 形走势 + 下部露干是盆景的"魂"，程序化生成时主干必须加正弦偏移，不能直上；② 云片式树冠——侧枝走平、叶簇成团，才有"一盆小宇宙"的压缩感，而不是一棵野树；③ 四季的"信物"——季节不靠换整棵树表达，靠信物：春天的花瓣、秋天的落叶、冬天的雪，信物对了季节就成立。
- **代码原创声明**：以上只学手法。递归分支（含 S 形主干/侧枝概率/时间窗分配）、对折叶形几何、实例化生长矩阵、四季颜色/粒子/积雪过渡、陶盆车削剖面、时间轴 scrub 逻辑全部手写原创，未复制任何现成树木生成代码。

## 动效拆解

| 模块 | 手法 |
|---|---|
| 递归树干 | 确定性随机（mulberry32 种子写死）：主干 4 段 S 形虬曲 + 侧枝（depth0 0.85 / depth1 0.55 / 深层 0.42 概率）+ 梢头 2–3 叉，最大深度 4；约 300 段枝全部 InstancedMesh 一次绘制 |
| 延时生长 | 每段枝有先序分配的生长时间窗（父先子后，t0 0.05→0.85）；逐帧按 g 重算实例矩阵：长度/半径按进度展开；叶片出生时间 = 所属枝段结束 + 0.015，smoothstep 展叶 |
| 叶簇 | depth4 枝端 4–7 叶 + depth3 枝端补叶，约 600 叶；对折叶形（Shape 尖椭圆 + 中线折 0.2 + 杯状弧度）；每叶独立相位微摆（±0.07rad 正弦） |
| 四季切换 | 叶色实例色向目标 lerp（1.8/s，单叶 0.9–1.1 jitter）；冬 foliage→0 落叶；粒子颜色/数量/速度/尺寸整体切换；土面积雪圆盘 + 盆沿雪环透明度 0→0.92 |
| 飘落粒子 | 220 点 CPU 更新：春陶土花瓣 / 夏浓绿微尘（70 粒）/ 秋赭叶 / 冬白雪；下落 + 正弦摇摆，落地回顶重生；圆形柔边精灵纹理（canvas 径向渐变程序化生成） |
| 陶盆 | LatheGeometry 车削剖面（盆体 + 外翻沿），陶土色粗糙 0.9；深色托盘 + 苔土面；PCFSoft 阴影落在宣纸地盘上 |
| 相机 | 整盆转台 0.05rad/s 缓旋 + 鼠标视差（lerp 2.5/s，±0.7/±0.4） |
| 深链 | `?g=0.85&season=2` 直达生长阶段/季节（截图与分享用） |

## 配置参数表

| 参数 | 位置 | 默认 | 说明 |
|---|---|---|---|
| `MAXD` | main.js | 4 | 递归最大深度；加大会指数增枝叶数 |
| `GROW_SECS` | main.js | 26 | 完整生长一次的秒数 |
| 枝段时间窗 | 生成后分配 | t0 0.05→0.85 / 宽 0.10 | 先序保证父枝先长；改宽窄调"抽枝"节奏 |
| `SEASONS` | main.js | — | 四季叶色/粒子色/数量/速度/尺寸/积雪开关，一处改全套 |
| 粒子上限 `PMAX` | main.js | 220 | 各季用 drawRange 取子集；低端机可降 |
| 种子 | `mulberry32(20261009)` | — | 换种子 = 换一盆新树；同一页面永远同一棵树 |
| 转台速度 | `animate` | 0.05rad/s | 关则只剩视差 |
| loader 兜底 | main.js | 4500ms | 超时强制进入完成态 |
| 配色 | CSS 变量 + SEASONS | — | `--paper:#F4F0E3` 宣纸 / `--ink:#1E2B22` 墨绿 / `--terra:#B4653F` 陶土；四季叶色均为三色家族内变化 |

## 「看起来不像 AI 写的」六项自查

1. **克制**：整页只讲一个主视觉——一盆正在生长的盆景。无多余装饰模块，粒子即季节信物，不另加。
2. **配色**：严格 3 色（宣纸/墨绿/陶土），禁用彩虹渐变；春夏秋冬的叶色/粒子色全部落在三色家族内（嫩绿/浓绿/赭/雪白为纸色的延伸）。
3. **字体**：中文标题宋体系衬线（Songti SC/STSong/SimSun 系统栈），英文小字大字距（.42em），季节按钮衬线体；零外部字体。
4. **文案**：真实感短句（"一岁枯荣，尽在此盆"），无 Lorem ipsum、无 emoji 列表（播放/暂停用 ❚❚/▶ 几何字形）。
5. **手工细节**：宣纸 vignette 暖暗角 + SVG feTurbulence 噪点（multiply 混合做纸纹）；按钮 hover 上浮 2px + 陶土光晕；滑杆填充用陶土渐变；hint 交互后/12s 后淡出。
6. **easing**：全站 `cubic-bezier(.22,1,.36,1)`，intro stagger 130ms；展叶 smoothstep、季节 lerp 1.8/s、落叶 2.2/s，有物理感。

## 重建方式

```bash
cd ~/workspace/fx-lab/bonsai-3d
cp index.src.html index.html
python3 ~/workspace/bin/fx-singlefile.py bonsai-3d
```

改 `src/main.js` 或 `index.src.html` 后重新跑上面三行即可。**禁止对已打包的 index.html 重复跑 singlefile**（importmap 已是 data:URL、main.js 已是 bundle，单向）。

依赖注意：打包需要 `/tmp/esb`（esbuild）与 `/tmp/three.module.min.js`；`/tmp` 可能被 VM 重置清空，缺失时重装：`mkdir -p /tmp/esb && cd /tmp/esb && npm i esbuild`，再用 esbuild 把 `vendor/three.module.js` `--format=esm --minify` 到 `/tmp/three.module.min.js`。

## 移动端说明

- 390×844 布局：标题缩小上移，控制面板贴底全宽（季节按钮横排 + 滑杆 + 播放键），hint 与生长读数隐藏（触屏直接拖）。
- 触屏：季节按钮/滑杆/播放键均为原生控件，`touch-action:manipulation` 防双击缩放。
- 像素比上限 2；实例总数约 900（枝 300 + 叶 600），中端机流畅，低端机可降 `PMAX` 或叶簇数量。
