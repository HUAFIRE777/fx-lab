# nebula-drift-3d · 星云漂流

一句话介绍：全屏粒子星云——九千颗星尘绕双旋臂缓慢漂流，鼠标视差推镜头，滚动加速穿越，紫雾/冰蓝两种色温。`huafire3d fx-lab — original implementation`

## 参考与借鉴点

- **对标对象**：天文可视化站的"旋臂星云"全屏 hero（双旋臂 + 中心辉光 + 星尘闪烁的构图）。
- **学了哪几个手法**（只学手法，不抄代码）：
  1. 双旋臂星尘分布：内密外疏、臂间留白，星云才有"旋"的感觉；
  2. 鼠标视差推镜头：镜头位移跟鼠标走，指数平滑，不晕；
  3. 滚动加速穿越：滚轮增量 → 穿越速度 + FOV 拉伸，速度感三件套只取两件（不用速度线，星云要静）。
- **代码原创声明**：旋臂生成、闪烁 shader、辉光精灵、视差/加速逻辑全部为手写 GLSL 与原创 JS，未引用任何原站源码；Three.js（MIT）仅作渲染载体。

## 动效拆解

| # | 动效 | 实现 |
|---|---|---|
| 1 | 双旋臂星尘（9000 点） | BufferGeometry + 自定义 ShaderMaterial：臂角按半径递增、亮度内密外疏；点大小按距离衰减、边缘柔化 |
| 2 | 星尘闪烁 | 每点独立相位 `sin(uTime·速率 + 相位)`，亮度 0.72–1.0 之间呼吸 |
| 3 | 中心辉光 | Canvas 径向渐变精灵，Additive 叠加，透明度 0.75–0.9 缓慢呼吸 |
| 4 | 鼠标视差 | pointermove → 镜头目标位移，`1-exp(-dt·2)` 指数追踪 |
| 5 | 滚动加速穿越 | wheel 增量累积 boost（上限 2.2），指数衰减；转速与时间流速同乘 `(1+boost)`，FOV 55→64 拉伸 |
| 6 | 色温预设 | 紫雾/冰蓝只调 `uHue` 混合系数，指数平滑过渡 |
| 7 | 漂流速度滑杆 | 0–3×，目标值经 `1-exp(-dt·4)` 平滑 |
| 8 | 加载态 | 「星云正在凝聚」+ 循环进度条；首帧+450ms / load+450ms / 3.2s / 5s 四重兜底必进完成态 |

## 配置参数

在 `src/main.js` 顶部 / uniform 处调整：

- `COUNT` 初值 `9000`：星尘数量
- `tgt.s` 初值 `1.0`：漂流速度（滑杆 0–300 → 0–3×）
- 旋臂张角 `r * 0.42`：越大旋臂越开
- 辉光精灵尺寸 `11`：中心辉光范围
- 配色：`:root` 中 `--night:#050510` `--violet:#8b5cf6` `--ice:#67e8f9`

## "看起来不像 AI 写的"六项自查

1. **克制**：全页只有一个主视觉动效（星云）；标题/控制条均为静态 UI，无第二主角。
2. **配色**：全页严格 3 色（深空 #050510 / 星云紫 #8b5cf6 / 冰蓝 #67e8f9），无彩虹渐变；预设只调两色配比、不引入新色。
3. **字体**：系统字体栈；巨型标题 `clamp(3rem,10vw,7.5rem)` 字距 -0.02em，kicker 字距 0.55em 大小 12px，层级分明。
4. **文案**：真实感中文短句（"把一片星云，收进一屏""深空从来不急"），无 Lorem ipsum、无 emoji 符号列表。
5. **手工细节**：星尘大小按亮度分档（少数亮星、多数暗尘）、中心辉光呼吸、滑杆 thumb 悬停发光、vignette + SVG 噪点、「星云正在凝聚」加载态。
6. **easing**：全部手写物理感缓动（`cubic-bezier(0.16,1,0.3,1)`、指数追踪 `1-exp(-dt·k)`），无默认 linear。
