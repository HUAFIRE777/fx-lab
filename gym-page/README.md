# 铁馆 IRONHOUSE · 健身房官网首页模板（gym-page）

综合健身房官网首页模板 —— hero 力量主张 + 团课周排期表 + 教练墙 + 私教三档价格 + 场馆环境 + 免费体验课预约表单，商用级，可直接改字上线。

`huafire3d fx-lab — original implementation`

## 参考来源（只学布局结构与交互编排，源码/文案/图片全部原创）

参考类型：国际连锁健身房官网（如 Pure Fitness / 24 Hour Fitness 一类站点的通用版式）。学到的布局点：

1. **顶部导航**：左品牌标识、中部菜单（团课/教练/价格/体验）、右"免费体验" CTA；滚动后透明→毛玻璃。
2. **hero 主张区**：一句训练主张大标题 + 副标题 + 双 CTA（免费体验/查看团课），配器械视觉。
3. **团课周排期表**：周一到周日按天切换的课程格子（时间/课程名/教练/强度）。
4. **教练墙**：教练卡片 = 专长 + 认证 + 一句话。
5. **私教价格三档**：单次 / 10 次卡 / 年卡，主推档高亮。
6. **场馆环境 + 预约 CTA + 页脚**：器械区/团课房/淋浴三项 → 免费体验课表单（姓名/电话/意向课程）→ 页脚（场馆信息/法务三件套/社交图标/版权行）。

## 动效拆解

1. **加载态**：全屏炭黑 loader（杠铃线稿 mark + 荧光柠檬进度条），DOM 就绪后最短 700ms 淡出，再触发 hero 入场；4s 兜底必达完成态。
2. **hero（主视觉动效）**：三行大字遮罩升起（`overflow:hidden` + 内层 `translateY(112%)→0`，`cubic-bezier(.19,1,.22,1)`，逐行 stagger .08/.2/.32s）；SVG 杠铃片左右错峰滑入（6 片，stagger .45→1.1s）；底部荧光柠檬跑马灯（无缝循环，微倾 -1.2°）。
3. **导航**：滚动 40px 切换 `.scrolled` 毛玻璃（`backdrop-filter: blur` + 半透明）；链接 hover 下划线生长；移动端汉堡→全屏抽屉。
4. **滚动 reveal**：`IntersectionObserver`（阈值 .12）给 `.reveal` 加 `.in`，各区块 stagger 递进上浮；`prefers-reduced-motion` 下全部跳过直达终态。
5. **排期表切换**：点天 → 旧格子右滑淡出（220ms）→ 渲染新一天 → 滑入；当天默认选中。
6. **hover 微交互**：课程卡/教练卡/场馆卡上浮 + 柠檬描边；教练头像微放大；价格主推卡整体放大 1.04；按钮上浮 + 柠檬光晕。
7. **手工细节**：全页 SVG `feTurbulence` 噪点（5%）+ 暗角 vignette；背景呼吸光斑 9s；滚动提示线循环下落；表单校验错误态；预约成功态（"收到，{name}！"）。

## 配置参数（`src/main.js` 顶部）

- `SITE` —— 站点信息变量（**买家改这里，一改全改**）：`name / phone / phoneHref / address / hours / icp / year`。页脚电话/地址/营业时间/版权行/备案号由 `data-site` 属性自动渲染。
- `LEGAL` —— 法务三件套文案对象（`privacy / terms / cookies`，每篇 `title + sub + points` 数组），改文案只改这里。
- `SCHEDULE` —— 团课数据（7 天 × 每天 4 节：时间/课程名/教练/强度 1–3），`DAYS` 为 tab 文案。
- `LOAD_MIN = 700` —— 加载态最短展示（ms）。

## 法务三件套（弹窗实现）

- 页脚"网站政策"三个按钮：**隐私政策 / 服务条款 / Cookie 政策**，点击弹模态弹窗（单弹窗壳 + JS 按 key 灌文案）。
- 关闭三通道：右上 ×（hover 旋转 90°）、点击遮罩、ESC；打开时 `body overflow:hidden` 锁定背景滚动；焦点自动进关闭钮，关闭后回到原焦点。
- 三篇文案均为真实感中文通用条款（隐私 5 条 / 服务 5 条 / Cookie 4 条，覆盖约课信息保存、退费规则、爽约规则等），无 Lorem。
- 社交媒体图标：inline SVG 四枚（微信/微博/小红书/抖音，几何线稿），hover 变柠檬色上浮。

## 六项"不像 AI 写的"自查

1. **克制**：整页只讲"流汗是最便宜的投资"一个主张；动效只有揭示/滑入/上浮/跑马灯四板斧，不堆砌。
2. **配色定死**：炭黑 `#121212` / 荧光柠檬 `#D4F542` / 纯白 `#FFFFFF` 三色全页统一（卡片用白色 alpha 做层次，无新增色相），无彩虹渐变。
3. **字号字距层级**：H1 `clamp(58px,9.5vw,132px)` 900 字重 .03em 字距；眉题 13px .5em 字距；价格 52px；教练名 20px。标题短促有力，呼吸感靠行高 1.06–1.18。
4. **文案真实感**："第一次练背，建议从划船机开始""跟不上节奏就先跟一半，剩下一半下次来拿""早上七点来，深蹲架不用排队"。无 Lorem、无 emoji 符号列表（强度用圆点，列表对勾用 SVG 蒙版）。
5. **手工细节**：噪点、暗角、跑马灯微倾、杠铃片错峰、滚动提示线、表单错误文案不说"格式错误"而说"手机号好像不对，再检查一下"。
6. **easing**：统一 `cubic-bezier(.19,1,.22,1)`（快出慢收物理感），呼吸/跑马灯用线性或 ease-in-out 往返。

## 源码结构

- `index.src.html` —— 开发源码（`<link href="styles.css">` + classic `<script src="src/main.js">`）
- `index.html` —— 最终单文件交付版（`fx-singlefile.py` 打包；**禁止二次打包**，改源码后重新 `cp index.src.html index.html` 再跑）
- `styles.css` —— 全部样式（变量/导航/hero/各区块/弹窗/响应式；未覆盖 `[hidden]{display:none}`）
- `src/main.js` —— classic 脚本：SITE/LEGAL/SCHEDULE 配置 + loader + 导航 + 抽屉 + 排期渲染 + reveal + 表单校验 + 法务弹窗（零依赖）
- 无 `vendor/` —— 本模板零外部依赖（纯 CSS/SVG 程序化视觉；无 Google Fonts、无 CDN、无 picsum，外链 grep 仅命中 SVG 命名空间字面 `http://www.w3.org/2000/svg`，无真实网络请求）

## 重建方式

```bash
cd ~/workspace/fx-lab/gym-page

python3 ~/workspace/bin/fx-singlefile.py gym-page
```

## 移动端说明

- ≤860px：导航收起为汉堡抽屉（全屏毛玻璃）；hero 改单列，杠铃视觉移到文案上方；价格/场馆改单列；CTA 表单全宽。
- ≤640px：教练墙单列；法务弹窗全屏式；跑马灯字号缩小。
- 触摸：所有 hover 微交互在触屏自动退化（无悬停即无触发），点击/切换/表单/弹窗逻辑与桌面一致；抽屉打开时锁定背景滚动。
- 已验证：390×844 真机视口截图（`../shots/gym-page-mobile.png`），排期 tab 可横向换行点选，表单三态正常。
