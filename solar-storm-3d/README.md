# solar-storm-3d · 太阳风暴

一句话介绍：一颗正在喷发的恒星——噪声火球表面翻滚，粒子射流向外抛洒，磁弧缓慢转动，日冕随耀斑闪亮，点击触发一次耀斑爆发。`huafire3d fx-lab — original implementation`

## 参考与借鉴点

- **对标对象**：天文可视化站的"太阳风暴"（翻滚火球 + 径向射流 + 日冕辉光的构图）。
- **学了哪几个手法**（只学手法，不抄代码）：
  1. fbm 火球表面：三色按噪声值分层（深红 → 橙 → 金），表面才有"翻滚"感；
  2. 射流循环再生：粒子从球面出发、飞远、变暗、重生，寿命驱动位置与透明度；
  3. 耀斑是"一瞬"：点击后强度指数衰减，日冕跟着亮一下就收。
- **代码原创声明**：火球 shader、射流系统、磁弧、日冕、耀斑逻辑全部为手写 GLSL 与原创 JS，未引用任何原站源码；Three.js（MIT）仅作渲染载体。

## 动效拆解

| # | 动效 | 实现 |
|---|---|---|
| 1 | 翻滚火球 | 自定义 ShaderMaterial：fbm 4 阶噪声驱动三色分层 + 边缘金色辉光 |
| 2 | 粒子射流（2200 点） | 每粒子方向/速度/寿命独立；位置 = 方向 ×（半径 + 射程 × 寿命），带切向漂移；寿命到头重生 |
| 3 | 磁弧 | 3 条细圆弧（半径 2.3/2.7/3.1），Additive 叠加，缓慢自转 |
| 4 | 日冕 | 径向渐变精灵，透明度 0.7–0.95 呼吸；耀斑时放大 9→10.6 |
| 5 | 耀斑爆发 | 点击画面（位移 < 6px 判定为点击）或点按钮：flare=1，指数衰减；射流速率 ×(1+2.2·flare)，火球增亮 0.7·flare |
| 6 | 拖拽旋转带惯性 | pointer 拖拽 → 角速度，松手后 `exp(-dt·3.2)` 衰减；待机自转 |
| 7 | 喷发强度滑杆 | 0–2×，目标值经 `1-exp(-dt·4)` 平滑 |
| 8 | 加载态 | 「恒星正在点燃」+ 循环进度条；首帧+450ms / load+450ms / 3.2s / 5s 四重兜底必进完成态 |

## 配置参数

在 `src/main.js` 顶部 / uniform 处调整：

- `JETS` 初值 `2200`：射流粒子数
- `tgt.rate` 初值 `1.0`：喷发强度（滑杆 0–200 → 0–2×）
- 射流射程 `2.3`：粒子飞出球面的距离
- 火球半径 `1.5`，日冕尺寸 `9`
- 配色：`:root` 中 `--night:#050505` `--ember:#f97316` `--gold:#fbbf24`

## "看起来不像 AI 写的"六项自查

1. **克制**：全页只有一个主视觉动效（喷发的恒星）；标题/控制条均为静态 UI，无第二主角。
2. **配色**：全页严格 3 色（漆黑 #050505 / 橙 #f97316 / 鎏金 #fbbf24），无彩虹渐变；火球三色是火焰本身的分层，不是装饰渐变。
3. **字体**：系统字体栈；巨型标题 `clamp(3rem,10vw,7.5rem)` 字距 -0.02em，kicker 字距 0.55em 大小 12px，层级分明。
4. **文案**：真实感中文短句（"恒星表面一次喷发""炸一朵耀斑给你看"），无 Lorem ipsum、无 emoji 符号列表。
5. **手工细节**：射流粒子大小按寿命衰减、磁弧三色粗细不一、日冕呼吸、滑杆 thumb 悬停发光、vignette + SVG 噪点、「恒星正在点燃」加载态。
6. **easing**：全部手写物理感缓动（`cubic-bezier(0.16,1,0.3,1)`、指数追踪 `1-exp(-dt·k)`），无默认 linear。
